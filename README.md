## Molecular Representation, Chemical-Space Distance, and Caco-2 Permeability Prediction

## Overview

This repository contains the computational notebooks, curated dataset, final figures, and result tables associated with the research manuscript:

Molecular Representation Shapes the Relationship Between Chemical-Space Distance and Prediction Error in Caco-2 Permeability Modeling

The study investigates how molecular representation influences the relationship between chemical-space distance and prediction error in Caco-2 permeability prediction.

## Research Objectives

- Compare Morgan fingerprints, RDKit molecular descriptors, and a hybrid molecular representation.
- Evaluate predictive performance under random and scaffold-based data splits.
- Investigate the relationship between nearest-neighbor chemical-space distance and absolute prediction error.
- Compare prediction errors across chemical-space distance groups (Q1–Q5).
- Examine how molecular representation affects error patterns and model generalization.

## Repository Contents

## Jupyter Notebooks

The repository contains 11 numbered Jupyter notebooks documenting the research workflow, including data mining, dataset auditing, exploratory data analysis, topological data analysis, molecular representation, model development, scaffold-based evaluation, and final results analysis.

"11_Preprocessing Validation and Corrected Models.ipynb"

## Corrected Analysis Workflow and Dependencies

Notebook 11 ("11_Preprocessing Validation and Corrected Models.ipynb") contains the corrected analysis and final results-consolidation workflow. It loads the curated dataset and saved molecular representations generated by earlier notebooks, including "RDKit_descriptor_chemical_space.pkl" and "Hybrid_chemical_space.pkl", rather than rebuilding these representations from scratch. These saved ".pkl" files are required to execute the relevant parts of Notebook 11 from start to finish. The repository currently provides the notebooks, curated dataset, final manuscript figures, and result tables; the saved representation files are not included.

## Molecular Representations

The study evaluates three molecular representations:

- Morgan fingerprints: 2,048-bit molecular fingerprints.
- RDKit descriptors: 205 molecular descriptors.
- Hybrid representation: A combination of Morgan fingerprints and RDKit descriptors.

The molecular representations were generated and saved during the chemical-space representation workflow. Notebook 11 uses saved RDKit descriptor and hybrid representation files for the corrected scaling analysis.

## Modeling and Evaluation

The study evaluates Random Forest, XGBoost, and LightGBM models under random train–test splits. Random Forest is also evaluated using a scaffold-based split.

Evaluation includes predictive performance metrics, Spearman rank correlation between chemical-space distance and absolute prediction error, and statistical comparisons between the closest and farthest chemical-space groups.

## Software and Dependencies

The analysis uses Python and cheminformatics and machine-learning libraries, including RDKit, pandas, NumPy, scikit-learn, XGBoost, LightGBM, SciPy, and Matplotlib.

The software versions used in the study are documented in the associated manuscript. Some notebooks require intermediate datasets or saved molecular representation files generated by earlier workflow steps.

## Reproducibility

To reproduce the analysis, follow the numbered notebooks in sequence and ensure that the required input datasets and intermediate files are available. The curated dataset and final manuscript figures and tables are provided in this repository.

The large saved molecular representation files used by some notebooks are not included in the repository at this stage. Consequently, certain notebooks may require these files to be regenerated before execution.
